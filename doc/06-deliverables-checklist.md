# Pre-Development Deliverables Checklist

Before design or coding starts, prepare these artifacts. Having them ready significantly reduces redesign effort later and ensures every module (appointments, prescriptions, pharmacy, inventory, billing, patient reminders) is built as one cohesive platform.

- [ ] Product Requirements Document (PRD) — see `01-PRD-overview.md`
- [ ] User personas and role definitions
- [ ] Feature list with priorities (tie to MVP phases in `03-user-journeys-integrations-nfr.md`)
- [ ] User journey maps — see `03-user-journeys-integrations-nfr.md`
- [ ] Information architecture / application sitemap
- [ ] Wireframes for each module — see `04-wireframes-patient-doctor-apps.md` and `05-wireframes-admin-app-design-system.md`
- [ ] Database schema (ER diagram) — informed by module data model in `02-modules-deep-dive.md`
- [ ] API specifications
- [ ] Permission matrix (who can access what — RBAC for Admin, Doctor, Receptionist, Pharmacy, Patient)
- [ ] UI design system (colors, typography, components) — see `05-wireframes-admin-app-design-system.md`
- [ ] Development roadmap with milestones
- [ ] Testing plan (functional, usability, and security)
